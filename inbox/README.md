# inbox —— 每天把 TSV 丢这里

把文件命名成 `2026-11-03.tsv` 并提交，GitHub Actions 会自动：

1. 读这个文件
2. 生成 `data/days/2026-11-03.json`
3. 重建 `data/index.json` 和 `data/bundle.js`
4. 把结果提交回仓库，并触发网页重新构建

文件名里的日期会被自动识别；不含日期的文件名（比如 `day1.tsv`）会用「运行当天」的日期。

格式（Tab 分隔，一行一条，首行表头可留可删）：

```
type	jp	reading	pos	cn	alt	example	exampleCn	tags
word	曖昧	あいまい	ナ形	暧昧；含糊	模糊	彼の返事は曖昧だ。	他的回答很含糊。	N2
grammar	〜かねない			很可能（发生不好的事）	有可能	この工事は間に合わないかねない。	这个工程很可能赶不上。	N2
```

- `type`：`word` 或 `grammar`
- `alt`：可接受的同义答法，用 `|` 隔开，用来放宽判分
- 拼音式字段可以留空；**`jp` 和 `cn` 不能为空**
- 就算 Tab 被编辑器换成了空格或逗号，脚本也会尽量识别（但示例句里含空格时可能串列，能上传原文件就别手打）
